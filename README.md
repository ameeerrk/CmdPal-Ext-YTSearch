# CmdPal-Ext-YTSearch

CmdPal-Ext-YTSearch is a custom extension for the PowerToys Command Palette. It lets you search YouTube directly from the command box without opening the browser first. Type your query, press enter, and the extension instantly opens YouTube with the search results.

This extension is built for faster workflow navigation and quick access to YouTube content through a simple command.

## Features
- Search YouTube directly from PowerToys Command Palette  
- Opens results in your default browser  
- Works instantly with any query  
- Lightweight and easy to install  
- No external dependencies

## How It Works
1. Open the PowerToys Command Palette  
2. Type your search text  
3. Trigger the extension command  
4. Your default browser will open YouTube with your query pre searched

## Installation
1. Download or clone this repository
2. Create a new extension on Command Palette with 'ytSearch' name
3. Replace this extension folder with your newly created ytSearch extension
4. Run 'Reload' command on Command Palette
5. Type 'YouTube Search' in Command Palette
6. You are ready to search

## Folder Structure
